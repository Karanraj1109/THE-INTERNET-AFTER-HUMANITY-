# THE INTERNET AFTER HUMANITY — V5

Cinematic long-form interactive web experience. V5 turns the archive into a century-spanning journey from the Connected Age to the Visitor in 2126.

## Main V5 additions
- Scroll-driven cinematic 8-chapter journey
- Era transitions from 1990–2126
- Sticky scene with procedural particles/orbits
- Danger/abyss/final visual states
- Journey progress HUD and chapter counter
- Smooth responsive transitions
- Existing V4 archive, fake internet, search, mail, forum, media, map, anomalies, terminal, Archivist, and branching endings retained
- English / Indonesian UI retained

Open `index.html` directly or serve the folder from any static host.
